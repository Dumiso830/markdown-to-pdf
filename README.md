# markdown-to-pdf

A Python CLI tool that converts Markdown files to PDF reports.

[![CI](https://github.com/yourusername/markdown-to-pdf/actions/workflows/ci.yml/badge.svg)](https://github.com/yourusername/markdown-to-pdf/actions/workflows/ci.yml)

[![License](https://img.shields.io/github/license/yourusername/markdown-to-pdf)](https://github.com/yourusername/markdown-to-pdf/blob/main/LICENSE)

## Installation

```sh
pip install markdown-to-pdf
```

## Usage

```sh
markdown-to-pdf input.md output.pdf
```

## Examples

```sh
markdown-to-pdf README.md report.pdf
```
